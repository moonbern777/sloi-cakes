# Торты «Слои»

Демо-сайт для портфолио. Кондитерская вымышленная.

Идея: страница и есть торт в разрезе. Каждый раздел сделан из своего материала, глазурь стекает с первого экрана и заливает его при прокрутке, а края разделов мягкие и пружинят, как крем.

## Запуск

Сборка не нужна, это обычные статические файлы. Модули не откроются напрямую с диска, поэтому нужен любой локальный сервер, например `npx serve .`

## Устройство

| Файл | Что делает |
| --- | --- |
| `js/cake.js` | Рецепты, цены и рисунок торта. Настоящий прайс клиента меняется здесь |
| `js/builder.js` | Конструктор, готовые торты и форма заказа |
| `js/textures.js` | Текстуры бисквита, конфи, крема и штрейзеля, рисуются на canvas |
| `js/glaze.js` | Глазурь на первом экране |
| `js/sprinkles.js` | Посыпка с простой физикой |
| `js/edges.js` | Волнистые края разделов |
| `js/main.js` | Плавная прокрутка и анимации при прокрутке |

Форма в демо только показывает подтверждение. На сайте клиента отправка подключается в `js/builder.js`, в обработчике `submit`.
